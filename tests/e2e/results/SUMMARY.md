## How to run (exact commands)

```bash
# build the snapshot binary (debug; serves repo frontend/dist — debug embed)
scripts/e2e/build-snapshot.sh --attempts 4

# Docker baseline instance (port 8731; 8720 production, 8721 is host nginx)
scripts/e2e/dev-instance.sh up docker
cd tests/e2e && npm install
node run.mjs --mode=docker --instance-root=/tmp/rast-e2e --scenario=all
node perf/quick-perf.mjs --mode=docker --instance-root=/tmp/rast-e2e

# Native instance (port 8732; only ONE native instance per host is possible)
RAST_E2E_ROOT=/tmp/rast-native-e2e RAST_E2E_BIN=/tmp/rast-e2e/bin/rast \
  RAST_E2E_BIND=127.0.0.1:8732 scripts/e2e/dev-instance.sh up native
node run.mjs --mode=native --instance-root=/tmp/rast-native-e2e --scenario=all
node perf/quick-perf.mjs --mode=native --instance-root=/tmp/rast-native-e2e

# restart only the web server (scenario j / recovery)
scripts/e2e/dev-instance.sh restart-server
```

Host-specific steps the dev script performs: installs `deploy/rast-linux.slice`,
creates the native data layout (`<data>/linux-apps{,/staging,/apps} 0750 rast`,
`profiles`/`linux-users` 0711 root:rast), fixes profile-ancestor permissions
(0711) and grants the `rast` user traverse ACLs on the repo path so the debug
server can read `frontend/dist`. Test credentials live in
`/tmp/rast-e2e/credentials.env` and `/tmp/rast-native-e2e/credentials.env`
(mirror in `tests/e2e/.env.local`, git-ignored).

## Explicitly not measured / limitations

* GPU/encoder utilisation and FPS (neither backend exposes it); Xpra encoder
  selection read from logs only.
* WAN/Cloudflare/nginx latency (loopback only).
* Input latency is an upper bound (Playwright + Chromium + screenshot polling).
* Docker image build time is an install metric (scenario a), not a launch one.
* Only one native-mode RAST instance can exist per host (host-global transient
  unit names); concurrent restarts by other agents invalidated some runs.
* Host load from parallel agent tests inflates absolute numbers; raw samples are
  in the JSON files.
