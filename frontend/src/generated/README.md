# Generated TypeScript

These files are generated by `ts-rs` from the Rust types in `crates/rast-api`.
Do not edit them by hand. Regenerate with `scripts/gen-api-types.sh`, which
empties this directory (keeping this README) and runs `cargo test -p rast-api`
(the output directory comes from `TS_RS_EXPORT_DIR` in `.cargo/config.toml`).
Commit the result. CI runs the same script and fails on any difference,
including leftover files.
